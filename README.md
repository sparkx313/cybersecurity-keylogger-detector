## 📌 Description
Endpoint Detection & Response (EDR) security script scanning running system processes for unauthorized keyboard hooks, hidden background execution, and suspicious process trees.

---

## 🚀 Key Features
- **Pure Python Implementation**: Lightweight, modular codebase with standard library efficiency.
- **Security-First Architecture**: Built for educational ethical security assessments, red team exercises, and blue team defense auditing.
- **Clear CLI Outputs**: Structured logging, status scores, and security alert formatting.

---

## 📦 Usage Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparkx313/cybersecurity-keylogger-detector.git
   cd cybersecurity-keylogger-detector
   ```

2. **Run the security tool**:
   ```bash
   python keylogger_detector.py
   ```
